# NirevOS agent authorizations. The only record that lets a development agent work on a Linear issue.
#
# This file lives in the public repository davecwallace3-blip/nirevos-agent-gate. The Claude GitHub App is not
# installed on that repository, so agents can read this file but cannot change it. Keep only issue numbers and dates
# here: this repository is public.
#
# Who edits it: David only, on github.com (pencil icon, "Commit directly to the main branch").
# Entries that arrive through a pull request or a merge are refused by the checker.
#
# Line formats (one per line; anything else makes the whole file invalid and every run stops):
#   GATES-PASSED <YYYY-MM-DD>                  David confirms DAV-7, DAV-9, DAV-13 are Done and DAV-10 has his
#                                             exception decision. Without this line no agent works.
#   AUTHORIZE DAV-<n> until <YYYY-MM-DD> [note]  One issue, valid through that date (at most 30 days ahead).
#   AGENTS-PAUSED                              Kill switch: while present, every agent run stops.
#
# Example (remove the leading "# " to use):
#   GATES-PASSED 2026-11-25
#   AUTHORIZE DAV-19 until 2026-12-02 supervised run
GATES-PASSED 2026-11-25
AUTHORIZE DAV-12 until 2026-12-02 supervised run
